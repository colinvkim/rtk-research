# Publication and privacy notes

This copy replaces personal filesystem paths with `/workspace/rtk-experiment` or `/home/researcher`. Finder metadata files were removed. The archive contains no Git history, environment files, databases, dependency environments, or nested archives.

The research findings and historical measurements are retained. Redaction changes the byte and token counts of some prompts, diagnostics, and captures. `studies/2026-09-07-gpt-6/publication-token-counts.json` records the original and published counts for affected text, without disclosing the removed paths. Historical token fields and aggregate statistics describe the original run; additional `published_*` fields describe the text distributed here. The source experiment remains local and is not included in this archive.

Capture and recovery hashes, and the study checksum manifest, were regenerated for the published copy. Hashes of the identifying original text are not distributed. This publication copy is not a byte-for-byte archive of the original run.

The audit scanned file contents and archive entries for personal paths, the local account name, contact addresses, private-key markers, common credential formats, and hidden metadata. No personal email addresses or credentials were found. The remaining `experiment@example.invalid` address is synthetic test data. Public source/documentation URLs, synthetic fixture names, study dates, and software versions remain because they support the research.

# RTK Research

Experiments and research notes on [RTK](https://github.com/rtk-ai/rtk), a CLI proxy that compresses command output for coding agents.

The research asks three questions:

- How much output does RTK save compared with ordinary and task-specific native commands?
- Does filtering hide information needed to complete the task?
- How do command selection and recovery reads affect the overall result?
